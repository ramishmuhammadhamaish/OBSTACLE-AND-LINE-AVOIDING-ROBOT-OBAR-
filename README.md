# OBSTACLE-AND-LINE-AVOIDING-ROBOT-OBAR-
An Obstacle and Line Avoidance Robot is an autonomous robotic vehicle designed to move through an environment while detecting and avoiding both physical obstacles and restricted lines or boundaries. It uses sensors to continuously monitor its surroundings and make decisions without direct human control.

The robot uses ultrasonic sensors to detect obstacles in its path and IR sensors to detect lines on the surface. An Arduino processes the sensor information and controls the motors through a motor driver. When an obstacle or unwanted line is detected, the robot changes its direction to avoid it and continues moving safely.
